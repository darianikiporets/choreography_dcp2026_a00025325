# Choreography creation : Music VS Silence

1. Project Overview

This project investigates how music affects the time I spend creating choreography.

I will collect my own data by recording the duration of each choreography creation session, whether I use music or work in silence, and other factors that may influence my creative process.

The dataset will be collected manually throughout the semester. The project will use Python, SQLite, pandas and Matplotlib to store, analyse and visualise the data.

2. Research Questions

Do I spend more time creating choreography with music or without music?

Does the number of new dance movements or sequences differ between sessions with music and sessions without music?

Is my self-rated creativity associated with the duration of a session?
